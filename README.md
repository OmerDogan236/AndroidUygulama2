# AndroidUygulama2

C# ve .NET MAUI ile geliştirilmiş çok sayfalı mobil uygulama (Bartın Üniversitesi Bilgisayar Mühendisliği, Ödev 2).

## Sayfalar

- **Kurlar** – döviz ve altın alış / satış fiyatlarını ve değişimini [genelpara](https://genelpara.com) API'sinden çeker
- **Haberler** – TRT Haber RSS akışını kategorilere göre listeler (Manşet, Gündem, Ekonomi, Spor…)
- **Hava Durumu** – girilen şehrin 5 günlük tahminini MGM'den gösterir
- **Yapılacaklar Listesi** – başlıklı görev ekleme
- **Ayarlar** – açık / koyu tema seçimi

## Teknolojiler

C#, .NET 7, .NET MAUI, XAML, HttpClient, JSON

## Çalıştırma

1. Visual Studio 2022'de ".NET Multi-platform App UI" iş yükünü kurun.
2. `MauiApp2/MauiApp2.csproj` dosyasını açın.
3. Hedef olarak Android emülatörü veya Windows Machine seçip çalıştırın.

Uygulama herhangi bir API anahtarı gerektirmez.
